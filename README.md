# 资料库

查询 [www.pomi.me](https://www.pomi.me) 上的开源项目、AI 新闻和 GitHub 榜单。

## 只想看

用浏览器打开 https://www.pomi.me 。不用下载，也不用安装 Python。

## Windows

从 [Releases](https://github.com/zhaokunzhang6-sudo/ziliao/releases) 下载 `ziliao.exe`，双击打开。不用安装 Python。打开后可以选择文件夹，把项目下载到那里。

## Cursor

把本仓库文件夹放到：

- Windows：`%USERPROFILE%\.cursor\plugins\local\ziliao`
- Mac：`~/.cursor/plugins/local/ziliao`

然后重启 Cursor。查询时会用到本机的 Python。

## Claude

把同一个文件夹放到 Claude 的用户插件目录，保留里面的 `.claude-plugin`。
